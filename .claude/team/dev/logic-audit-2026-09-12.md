# Logic-connection audit — 2026-09-12

Phase 2, item 3. Skeleton by Dmitri; **each owner fills in their own rows and does not rewrite
anyone else's.**

For each feature, trace **UI → hook → mutation/query → Supabase table, function or bucket** and
confirm every hop is real. Then set `status`:

- `verified` — you followed every hop and can name each one. Reading the file is not verification;
  rendering it, running it, or querying the database is.
- `gap` — a hop is missing, mocked, inconsistent, or dead. Say what, in the evidence column.
- `fixed` — it was a gap and you closed it in this phase. Name the commit-free diff.

**Evidence** is the load-bearing column. "Looks right" is not evidence. A query transcript, a jest
fixture, a render assertion, a `supabase functions list` output — those are.

Rows pre-filled with a status are ones I established while planning; re-verify rather than trust
them.
